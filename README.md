## The entry

`main.py` writes one commit message to `/output/entry.txt`: the note an AI agent
leaves after a long night fixing its own bugs. 82 characters, one line,
deterministic output.

> fix: fixed the bug I wrote at 2am with a worse bug I wrote at 4am. it ships at 9am

The joke is the loop: the agent repairs the bug it wrote at 2am with a worse
bug it wrote at 4am — and the worse bug ships at 9am. Flat machine voice,
quiet dread, no stock punchline.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```
